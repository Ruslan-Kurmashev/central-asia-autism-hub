# AutismHub decision register

This directory records explicit, owner-approved changes to product policy or technical standards that supersede older planning statements. An entry is not evidence that a technical implementation was changed unless linked code or a verified commit is also present.

## Decision rules

1. Use an ISO date and descriptive filename.
2. State the decision, why it was made, affected paths, and which earlier rule it supersedes.
3. Explicitly distinguish approved intent from implementation and independently verified operation.
4. Update the relevant canonical `docs/` policy and `AGENTS.md` in the same change.
5. Do not silently reinterpret decisions. Amend them with a new dated record.
6. Never use a decision log to override medical safety, licensing, privacy, or repository access constraints.
