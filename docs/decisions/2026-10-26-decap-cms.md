# Decision: document implemented Decap CMS

- Date: 2026-10-26
- Status: approved documentation correction
- Scope: repository technical plan and editorial workflow
- Supersedes: the statement in `docs/07-technical-plan.md` that the MVP has no administrative CMS

Decap CMS is present under `public/admin/` and its `config.yml` uses the `turbo-github` backend, `main`, and `editorial_workflow`. The CMS edits validated Markdown in GitHub. It does not grant site visitors accounts, collect visitor submissions, or require a database.

The committed configuration has a Turbo site ID. Authentication and editorial access must be verified as a separate runtime check, not inferred from the ID.

Updated authoritative documents: `docs/07-technical-plan.md`, `docs/decap-cms.md`, and `AGENTS.md`. No CMS functionality is being added by this decision.
