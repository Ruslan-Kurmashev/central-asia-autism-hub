## Очередь публикаций без срока пересмотра

`npm run check:editorial-review-due` теперь дополнительно выводит каждый файл без `reviewDueAt` со значениями риска, раздела, языка, даты публикации и последнего изменения, а также добавляет `missingDetails` в JSON-отчёт Actions. Очередь не получает вымышленные даты автоматически. Сначала следует установить тип содержания, актуальные источники, разумный период проверки и ответственного редактора, затем документировать решение и обновить отдельный материал.

В системе аудитных статусов нельзя обозначать "полностью проверено" на основании этого частичного отчёта.
